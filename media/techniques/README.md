# Аудио техник

Файлы раздаются как `/media/techniques/{technique_id}_audio.mp3` (см. `MEDIA_DIR` в `src/index.ts`).

Имена файлов, длительности и транскрипты — в `data/audio_scripts.json`.
Связность «техника ↔ транскрипт ↔ файл» проверяет `python scripts/validate_catalog.py --audio`.

Записан 1 файл из 16 (`1_audio.mp3`), остальные 15 валидатор показывает предупреждением.

## Требования к записи (ответы методолога 27.09, п. 6)

| Параметр | Значение |
|---|---|
| Формат | MP3, 128 kbps |
| Частота | 44.1 кГц |
| Каналы | Моно |
| Длительность | по `audio_duration_seconds` из JSON, допуск ±5 сек |
| Имя файла | `{technique_id}_audio.mp3` |

Голос: тёплый, бережный, спокойный, на «ты», медленный размеренный темп —
интонация поддерживающей подруги, а не наставника. Избегать назидательности и
«пластмассовой» приветливости.

Паузы из `pauses[]` выдерживать буквально по секундам: они часть методики, а не
оформление. Пример: `{"at": "после расслабления кулаков", "duration_sec": 3}`.

Исполнитель: профессиональный диктор, женский голос 30–45 лет. Допустим TTS с
тёплым голосом (например, Yandex SpeechKit, голос «alena»).
